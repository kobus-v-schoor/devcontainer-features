## OS Support

This Feature should work on recent versions of Debian/Ubuntu-based distributions with the `apt` package manager installed.

`bash` is required to execute the `install.sh` script.

Node.js 20.6.0 or newer and npm are required to install Pi. The feature depends on the `ghcr.io/devcontainers/features/node` feature, but you can also provide Node.js via another method (e.g., a base image with Node.js pre-installed).

## Installation

Pi is installed globally via `npm install -g --ignore-scripts @earendil-works/pi-coding-agent`.
